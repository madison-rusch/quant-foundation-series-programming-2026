# Homework Submissions — Lesson 4

This folder holds student submissions for the Lesson 4 data-analysis exercise.

## Files in this folder

- **`SUBMISSION_TEMPLATE.md`** — The complete guide for submitting your homework. Read this first.
- **Student submissions** — your analysis script (`<your-name>_analysis.py`), your updated chart
  (`<your-name>_chart.png`), and your stakeholder summary, following the template.
- **`README.md`** — This file.

## Quick start

1. Read [SUBMISSION_TEMPLATE.md](SUBMISSION_TEMPLATE.md).
2. Add at least one more calculation and update the chart.
3. Write a 3–5 sentence plain-English stakeholder summary.
4. Add your files here and open a PR — see [../README.md](../README.md) for the full steps.
