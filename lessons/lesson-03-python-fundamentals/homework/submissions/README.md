# Homework Submissions — Lesson 3

This folder holds student submissions for the Lesson 3 scraping exercise.

## Files in this folder

- **`SUBMISSION_TEMPLATE.md`** — The complete guide for submitting your homework. Read this first.
- **Student submissions** — your extended scraper (`<your-name>_scraper.py`), your cleaned data
  (`<your-name>_data.csv`), and your prompt notes, following the template.
- **`README.md`** — This file.

## Quick start

1. Read [SUBMISSION_TEMPLATE.md](SUBMISSION_TEMPLATE.md).
2. Extend the in-class scraper to pull at least one more data point.
3. Save a clean CSV — **you need it for Lesson 4.**
4. Add your files here and open a PR — see [../README.md](../README.md) for the full steps.
