# Homework Submissions — Lesson 2

This folder holds student submissions for the Lesson 2 plan/code/review exercise.

## Files in this folder

- **`SUBMISSION_TEMPLATE.md`** — The complete guide for submitting your homework. Read this first.
- **Student submissions** — `<topic>_<your-name>.py` (your annotated script) plus your prompt notes, following the template.
- **`README.md`** — This file.

## Quick start

1. Read [SUBMISSION_TEMPLATE.md](SUBMISSION_TEMPLATE.md) — it covers the exact format for your script and PR description.
2. Plan your script, then prompt Claude to write it.
3. Annotate at least 3 lines, refine your prompt once, and note what changed.
4. Add your files here and open a PR — see [../README.md](../README.md) for the full steps.
