# Demo 5 — AI for Interview Prep

Roughly 15 minutes. Same bond thread as the rest of the lesson — this time the topic is yield to maturity (YTM), which ties directly into the homework.

## 1. AI as a mock interviewer (5 min)

Prompt Claude live:

```
Quiz me on yield to maturity like an interviewer would. Ask me one question, wait for my
answer, then ask a harder follow-up based on what I said. Don't give me the answer up front.
```

Have a student answer out loud (or take a volunteer answer from chat). Let Claude ask its
follow-up. The point: Claude adapts its next question to the actual answer given, the same way
a real interviewer probes a weak spot.

## 2. Explain it back, then get critiqued (7 min)

Prompt:

```
I'm going to explain yield to maturity in plain English. Critique my explanation — tell me
what's missing, what's wrong, and whether an interviewer would be satisfied.

My explanation: [student's plain-English explanation, e.g. "YTM is the return you'd get if
you bought the bond today and held it to maturity, assuming all coupons get reinvested at
the same rate."]
```

Watch for Claude to flag specifics: did the explanation mention the reinvestment assumption?
Did it distinguish YTM from current yield or coupon rate? Did it mention that YTM moves
inversely with price?

## 3. Why this matters more than "give me the answer" (3 min)

Ask the class: *"What's different about this compared to just asking Claude 'what is YTM'?"*

- Explaining a concept out loud exposes gaps that silently reading a definition doesn't.
- A critique from AI is low-stakes practice for a real interview — you can be wrong here for free.
- This mirrors the homework's optional exercise: explain, get critiqued, refine.

## Talking points

- Using AI to check your understanding is different from using it to skip building understanding — the value is in the back-and-forth, not the first answer.
- This is the same Plan/Code/Review instinct applied to studying: plan what you think you know, "code" (say) your explanation, review via the AI's critique.
- Encourage students to try this on their own for the homework's optional mock-interview step, using their chosen FinMath topic.
