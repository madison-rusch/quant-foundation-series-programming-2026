# Homework Submissions — Lesson 5 (optional)

This folder holds optional capstone submissions. There's no required homework — the course is
complete — but if you extend the analysis (Option A in [../README.md](../README.md)), submit it here.

## Files in this folder

- **`SUBMISSION_TEMPLATE.md`** — the format for an optional submission. Read this first.
- **Student submissions** — your analysis script (`<your-name>_analysis.py`), your chart
  (`<your-name>_chart.png`), and your stakeholder summary in the PR description.
- **`README.md`** — this file.

## Quick start

1. Read [SUBMISSION_TEMPLATE.md](SUBMISSION_TEMPLATE.md).
2. Point the pipeline at a new index or period and add at least one new calculation.
3. Write a 3–5 sentence plain-English stakeholder summary.
4. Add your files here and open a PR — see [../README.md](../README.md) for the full steps.
