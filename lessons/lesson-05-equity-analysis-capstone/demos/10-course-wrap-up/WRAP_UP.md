# Demo 10 — Course Wrap-Up

Roughly 5 minutes. Recap the toolkit, point forward, and **end on energy**. This is the last thing
they do before their masters program begins — they should leave feeling capable, not overwhelmed.

## The toolkit they now have

| Tool | What it's for | Where they learned it |
|---|---|---|
| Git & GitHub | Version control, collaboration, self-review via PRs | Lesson 1 |
| VSCode + Claude Code | Their development environment | Lesson 1–2 |
| Plan / Code / Review | The AI workflow — scope, generate, verify | Lesson 2 |
| BeautifulSoup & requests | Gathering data from the web | Lesson 3 |
| Pandas | Working with tabular & time-series data | Lesson 4 |
| NumPy | The vectorized engine under Pandas | Lesson 4 |
| matplotlib | Turning analysis into a clear chart | Lesson 4–5 |
| Debugging | Reading errors, breakpoints, inspecting variables | Lesson 1, 4 |
| Big O, algorithms, Python patterns | The CS vocabulary for interviews & review | Lesson 5 (first half) |

Today they used **all of it, in one pipeline**, to answer a real brief. Say that out loud.

## How to keep building independently

- **Run Claude as a mock interviewer regularly** — the prompt from Demo 9 works any time, for free.
- **Keep a GitHub repo of practice scripts.** Every small analysis is a portfolio piece and a PR to review.
- **Revisit the first-half references** ([Big O](../01-big-o-notation/big-o-notation.md),
  [algorithms](../02-algorithms/common-algorithms.md),
  [Python patterns](../03-python-keywords-patterns/python-keywords-and-patterns.md),
  [interview bank](../04-interview-question-bank/interview-question-bank.md)) at your own pace before the masters starts.
- **Repeat today's analysis** on a different index or time period (see the homework).

## The final message

> You are **not** expected to memorize everything. You are expected to know how to *find answers, read
> code, and use your tools confidently.* That's what this course gave you — and it's exactly what the
> next two years will ask of you.

Congratulate them. They built a real, reproducible piece of quantitative research today, end to end.
They're ready.

## Talking points

- Frame the course as one continuous arc, not five separate lessons: environment → AI workflow →
  Python & data → analysis & visualization → doing it for real.
- The GitHub Issues they logged all term became the first-half content and the mock-interview themes —
  their questions literally shaped this lesson. Point that out; it reinforces the habit.
- End early rather than late. Leave them energized, not drained.
